5. History of HTML

  • 1989: World Wide Web proposed.
  • 1991: Early HTML introduced.
  • 1995: HTML 2.0 published.
  • 1997: HTML 3.2 and HTML 4.0.
  • 1999: HTML 4.01 released.
  • 2014: HTML5 became a W3C Recommendation.
  • Today: HTML follows a Living Standard.

Conclusion
